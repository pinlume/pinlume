## 为什么是 Pinlume？

Pinlume 是一款为高频桌面操作而生的原生 macOS 工具：小、快、流畅，常驻菜单栏却能覆盖从截图、贴图、标注到 OCR、翻译和录制的一整条路径。它不需要网页容器，不打断工作流，也不把你的内容上传到自己的服务器。

- **截图、标注、贴图一气呵成**：窗口吸附、快捷复制、原位固定、缩略与再次编辑，操作始终在屏幕上完成。
- **长图与录屏都不离开桌面**：滚动捕获自动拼接长图；区域或全屏录制可直接导出 MP4/GIF，再裁剪交付。
- **专业级标注，仍然轻快**：箭头、文字、画笔、形状、编号、图章、马赛克、模糊、放大镜和测量工具集中在一个画布里。
- **透明标注与演示画笔**：不截取桌面，只把标注固定在屏幕上；演示时可直接圈画、强调、指引，结束后干净撤销。
- **看见即翻译**：Apple Vision OCR、截图翻译和其他 App 选中文字翻译，减少复制粘贴与窗口切换。
- **从录制到交付**：录制区域或全屏，导出 MP4/GIF；可裁剪、导出，并按需上传到自己的云盘或对象存储。
- **隐私由你掌控**：没有遥测和分析；在线翻译、上传服务均由你主动选择和授权。

## 快速开始

正式版发布后，下载并将 `Pinlume.app` 移到“应用程序”文件夹，首次启动后按系统提示授予所需权限。

1. 启动 Pinlume。
2. 按 `Command + F1` 开始截图。
3. 拖动选区，用工具栏标注；按 `Command + C` 复制，或按 `F3` 贴在屏幕，可以 `shift + 双击` 缩小贴图，双击关闭贴图。
4. 按 `Option + 2` 和 `Option + F` 翻译或截屏翻译，`Shift + Option + F` 选区OCR 识别文字;
5. 按 `Esc` 取消当前操作或关闭弹窗。

### 从源码构建

需要 macOS 12.3 或更高版本，以及 Xcode。

```bash
# 仅构建固定身份的 Debug App
scripts/build-pinlume.sh

# 构建并启动 Debug App
scripts/run-pinlume.sh

# 安装本地构建副本到 /Applications，用于阶段性体验
scripts/install-pinlume.sh
```

本地构建使用 `Pinlume`、Bundle ID `com.pinlume.app` 和 URL Scheme `pinlume://`。本地构建签名仅用于稳定权限与本机体验，不等同于正式发布包。

### 捕获与贴图

- **即时截图与窗口吸附**：全局快捷键进入选区；可切换窗口吸附或截取整屏。
- **选区控制**：可设置精确像素尺寸和常用宽高比；拖动时支持边界吸附。
- **快速捕获**：回车和快速捕获可按设置复制、保存或固定到屏幕。
- **滚动捕获与延时截图**：支持纵向或横向滚动拼接，以及截图前倒计时。
- **固定到屏幕**：把选区或剪贴板图片固定为浮动贴图；可拖动、缩放、缩略、再次编辑或关闭。
- **透明标注**：不截取桌面内容，只把你绘制的箭头、文字、图章等标注以透明贴图固定在屏幕上；
- **演示画笔**：在当前屏幕上直接圈画和指引，随时撤销或结束，不生成截图文件，适合在演示、讲解或协作时强调界面内容。

### 标注与编辑

- **箭头、线条和形状**：支持多种箭头样式、矩形、椭圆、填充、圆角与旋转。
- **文字、画笔与编号**：富文本、铅笔、记号笔和自动递增编号。
- **图章**：内置 Emoji 或导入任意图片；支持保持比例缩放和旋转。
- **遮挡与隐私处理**：马赛克、模糊和实色遮挡；可自动识别邮箱、电话、银行卡、API 密钥等常见敏感文本，并辅助遮挡人脸、人物或全部文字。
- **辅助工具**：测量、放大镜、聚光灯、取色器、对齐参考线与撤销/重做。
- **独立编辑器**：可对图片继续标注、裁剪、翻转、缩放、粘贴图像和添加新的截图。

### OCR 与翻译

- **OCR**：使用 Apple Vision 提取截图文字，并可复制结果。
- **截图翻译**：识别截图中的文字后翻译；可选择翻译目标语言。
- **选中文字翻译**：在设置中开启后，可通过快捷键翻译其他 App 中当前选中的文字；首次使用时按 macOS 要求授予辅助功能权限。
- **二维码与 AI 搜索**：可识别二维码、复制或打开内容，并可将识别结果交给 Google AI 搜索。
- **隐私与网络选择**：在线翻译、Google AI 搜索及上传仅在你主动选择后联网；相关 Google 服务需要可访问其服务的网络环境。

### 适合谁用？

- **开发者、设计师与 vibe coding 重度患者**
- **经常沟通与写文档的人**：快速截取、标注、贴图，把重点说清楚。
- **电脑协作者**：用箭头、透明标注和演示画笔讲解界面、定位问题、记录反馈。
- **需要读外语资料的人**：截图 OCR 或选中文字翻译，少一次复制粘贴和窗口切换。
- **需要录制教程或复现问题的人**：从录屏、裁剪到导出都在同一个原生 App 中完成。

### 屏幕录制

- 录制区域或全屏，导出 MP4 或 GIF。
- 可选择系统音频、麦克风和鼠标点击高亮。
- 内置视频编辑器支持裁剪、播放、静音、保存与导出。

### 输出、历史与上传

- **输出格式**：PNG、JPEG、HEIC、WebP 和 AVIF，并可调整质量与 Retina 降采样。
- **历史记录**：保存最近截图，可重新打开、复制、保存、固定或编辑。
- **可选上传**：支持 Google Drive、imgbb 和兼容 S3 的存储服务；仅在你主动启用和执行上传时发送图片或视频。
- **截图美化**：可添加背景、窗口边框、阴影与渐变样式。

## 权限与隐私

Pinlume 会在对应功能首次使用时说明并请求权限：

- **屏幕录制**：截图、窗口吸附、滚动捕获和录制所必需。
- **辅助功能**：仅在你主动开启“翻译选中的文字”后，用于读取其他 App 当前选中的文字。
- **麦克风**：仅在你选择录制麦克风声音时请求。

Pinlume 默认不收集遥测、分析或崩溃报告。截图、录制、历史、设置和诊断信息保留在你的设备上；可选上传和在线翻译的边界见 [PRIVACY.md](PRIVACY.md)。

## 系统要求

macOS 12.3（Monterey）或更高版本。部分 OCR、翻译或视觉能力取决于所运行的 macOS 版本和系统提供的框架。
