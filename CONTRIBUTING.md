# Contributing to Pinlume / 参与贡献

> **Pinlume** is currently maintained independently and does not accept pull requests at this time. You are welcome to open an issue for bug reports, feature requests, or discussion. Please contact the maintainer before starting any code contribution.
>
> **映隅** 目前由维护者独立开发，暂不接收 Pull Request。欢迎通过 Issue 反馈问题、提出功能建议或参与讨论；如希望贡献代码，请先联系维护者沟通。

## Issues

- **Bug reports / 问题反馈：** Include your macOS version, Pinlume version, steps to reproduce, and screenshots or screen recordings when helpful. (请尽量提供 macOS 版本、Pinlume 版本、复现步骤，以及必要的截图或录屏。)
- **Feature requests / 功能建议：** Explain the problem you want to solve and the workflow you expect. (请说明希望解决的问题与理想使用流程。)

## Contact
